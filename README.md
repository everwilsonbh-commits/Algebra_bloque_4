# Bloque 4 · Inecuaciones y funciones

Repaso de álgebra para 4.° de secundaria: 5 sesiones (4 de 30 min y 1 de 45 min).

- `index.html`: página interactiva con los ganchos animados, candados con comprobación de clave y tarjetas de salida.
- `Bloque4_Inecuaciones_y_Funciones.docx`: versión en Word para imprimir.

## Sesiones
1. Inecuaciones lineales y compuestas ("El taxi")
2. Inecuaciones cuadráticas ("El balón en la cancha")
3. Función lineal ("Alquiler de bicis")
4. Función cuadrática ("El vértice del balón"), 45 min
5. Integradora ("Ver una inecuación")
